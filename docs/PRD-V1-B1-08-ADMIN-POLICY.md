# PRD-V1-B1-08-P | 管理员政策录入与批量 Markdown 发布

| 字段 | 内容 |
|---|---|
| 所属阶段 | B1.8 / B18-009 |
| 版本 / 状态 | V1.1 / 已完成 |
| 权限 | 仅平台管理员 |
| 数据底座 | standalone PostgreSQL |

## 1. 范围

管理员政策中心支持手工表单新增，以及一次选择或拖入最多 20 个 Markdown 文件批量解析。单文件最大 2 MB，不设置整批总大小上限。Markdown 解析结果进入可编辑表单，管理员逐条核对后选择保存草稿或发布。

第一期不支持 PDF、DOCX、OCR、ZIP、文件夹上传、自动联网核验、AI 元数据生成或物理删除。

## 2. Markdown 合同

每个文件使用 UTF-8 和 YAML front matter：`title`、可选 `document_no`、`issuing_organization`、`published_date`、`effective_status`、可选 `source_url`、可选 `document_url`；分隔线后的 Markdown 正文作为政策正文。系统提供示例模板下载。

文件名只用于展示。地区、ID、哈希、上传人、发布人和时间由服务端生成。未知字段、非法日期/状态/URL、空正文和超过 2 MB 的文件按单项失败处理，不阻断批次内其他文件。

## 3. 生命周期

政策状态为 `draft`、`published`、`withdrawn`。草稿只对管理员可见；普通政策中心和后续检索只读取已发布记录。已发布政策可撤回但不可物理删除，撤回必须填写原因。

批量发布按项目逐条处理，一个项目失败不回滚其他成功项目。重复点击不得创建第二条政策。

## 4. 重复检查

发布前由服务端重新检查：Markdown 文件哈希、最终正文哈希、发文字号、来源 URL、标题与发布机构组合。完全相同的文件或正文阻止发布；疑似修订仅提示管理员确认，第一期不建立版本链。

## 5. 管理员页面

路由为 `/admin/policies` 和 `/admin/policies/new`。管理员可查看草稿/已发布/已撤回列表；新增页可切换手工录入和批量 Markdown，查看每项解析状态、编辑、预览、选择并保存草稿或发布。非管理员看不到入口且后端返回 403。

## 6. 验收

- 手工录入可保存草稿、发布并出现在普通政策中心。
- 最多 20 个 Markdown 可批量解析；不限制批次总大小，但单文件超过 2 MB失败。
- 单项解析失败不影响其他项目；可编辑和预览后发布。
- 示例模板可下载并成功解析。
- 普通用户只看到 `published`；撤回后不可见且审计保留。
- 重复内容、重复发布、跨角色访问均安全拒绝。

2026-09-06 已在本机 standalone `aipolicy_local` 完成验收：`0007` 应用成功且既有 20 条政策 ID/正文哈希不变；管理员通过 Markdown 示例、混合有效/失败批次、手工草稿、发布、重复拒绝和撤回流程；普通用户仅看到已发布记录；桌面/移动管理员页面无横向溢出。单批总大小未设置限制，单文件限制 2 MB、批次上限 20 个。
