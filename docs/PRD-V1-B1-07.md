## 1. 目标与边界

B1.7 是 B1.1–B1.6 的第一批跨模块联调和演示环境收口，不新增用户业务流程。它验证真实配置下的数据库 revision、表/RLS、35 个部门绑定、路由和现有自动化门禁，并提供只处理明确 B1.7 演示标记记录的安全重置命令。

本次不包含真实 RAG 实现、Auth 账号创建、数据库迁移、政策库导入、普通用户咨询删除、全库清空、消息时间线或补充说明。

## 2. 交付物

- 只读集成审计：只输出命名检查和聚合状态，不输出 URL、令牌、用户 ID 或咨询正文。
- 双重确认演示重置：目标绑定失败、缺少 `--confirm` 或没有 B1.7 标记时均安全失败/空操作；应用时单事务删除标记工单及依赖记录。
