## Why

B1.1 到 B1.6 已分别完成，但进入下一阶段前需要一次可重复的跨角色联调和演示环境收口。B1.7 将验证既有身份、分类、政策问答、咨询闭环和历史问答之间的边界，并提供只处理明确 B1.7 演示标记记录的受保护重置流程。

## What Changes

- 新增只读的第一批集成审计，覆盖数据库 revision/表与 RLS、部门绑定完整性、业务 API 路由、安全错误和前端回归门禁。
- 新增双重确认、目标绑定、事务保护的 B1.7 演示重置；默认只预检，删除范围仅限明确带 B1.7 演示标记的咨询及其关联事件/公开投影。
- 记录跨角色联调矩阵和干净演示环境证据，不修改真实用户咨询、政策库、Auth 身份或外部 RAG 配置。

## Capabilities

### New Capabilities
- `integration-acceptance`: 第一批跨模块联调审计、演示数据边界和安全重置。

### Modified Capabilities
- 无。B1.7 不改变 B1.6 用户可见业务合同。

## Impact

- 新增后端运维脚本、单元测试和验收记录；不新增业务 API、数据库表或前端路由。
- 复用现有 Supabase target binding、数据库 session、咨询/历史问答模型和前端测试命令。
- 重置命令不创建 Auth 用户、不运行迁移、不读取或输出凭据；不匹配目标或标记的数据时安全失败/空操作。
